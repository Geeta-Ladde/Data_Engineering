---

## 📋 Framework Applied

Each experiment includes:
- **Hypothesis** — clear cause and effect statement
- **Test Cell Allocation** — control and treatment group splits with sample sizes
- **Leading Metrics** — observable within 2–4 weeks
- **Lagging Metrics** — observable after 6–12 weeks
- **Counter Metrics** — monitoring for unintended negative impact
- **Strategic Prioritization** — ranked by complexity and expected impact
