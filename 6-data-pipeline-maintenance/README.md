## 📌 What's in This Project

This project defines the complete operational framework for a 4-person
data engineering team managing investor-facing and experiment-supporting
pipelines across profit, growth, and engagement business domains.

## 📋 Key Sections

- **Pipeline Ownership Matrix** — Who owns what, primary and secondary owners, SLAs
- **On-Call Rotation Schedule** — Q4 2025 and Q1 2026 with holiday coverage policy
- **Investor Reporting Runbooks** — Detailed failure scenarios for all 3 P0 pipelines
- **Incident Response Protocol** — P0/P1/P2 severity levels and communication plan
- **Maintenance Windows** — Weekly and quarterly scheduled maintenance
- **Escalation Path** — On-call → Secondary → Team Lead → VP of Data → CTO
